# 四种动态运动类别

| 名称 | 含义 | 标签值 |
|---|---|---|
| ENTERING | 进入，当前深度位于历史静态区间近侧 | 1 |
| LEAVING | 离开，当前深度位于历史静态区间远侧 | 7 |
| APPROACHING | 接近，深度低于历史全观测区间，满足径向运动检查 | 3 |
| RECEDING | 远离，深度高于历史全观测区间，满足径向运动检查 | 2 |

论文第3.4节仍是两组检测机制，代码输出拆为四种运动标签；不是四套独立算法。论文联合检测进入/离开，没有给出独立四分类真值规则，本实现按深度偏差符号拆分进入/离开，是工程命名约定。相同点可能满足多组判据，保持进入/离开优先，不把这些标签解释成互斥的真实物体运动语义。

原 Case1 系列方法改为 EnteringLeaving，Case2 改为 Receding，Case3 改为 Approaching。论文分支分别累计四类票数，接近与远离的速度阈值分别传播，避免相反方向共享票数。聚类、历史深度提交和动态去除统一接收四类；原分类测试加入离开方向检查。

原M-detector检测与聚类补全的进入/离开标签根据历史静态深度偏差选择；缺少方向证据或平票时沿用 ENTERING 兼容标签，该标签不等于已证实的进入运动。聚类扩展点仍被排除为动态点。

ROS配置中的 case1/2/3 参数键保留兼容，仅用于原M-detector分支。前端 /fusion/dynamic_lidar 仍是合并动态点云，没有增加四个分类话题。该点云不携带四类标签；四类名称用于内部状态。旧的三组聚类诊断计数中进入/离开共用第一组。
