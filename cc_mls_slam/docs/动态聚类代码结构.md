# 动态物体聚类模块整理（2026-09-15）

本次是对当前融合库的结构重构，不是更换动态检测算法。原始输入点云不被擦除；该模块输出与输入逐点对应的标签：-1 无效、0 静态、1 动态，供后续静态点筛选使用。

## 文件职责

| 文件 | 负责的工作 |
| --- | --- |
| `src/dynamic/DynObjCluster.cpp` | 主流程、种子体素聚类、候选包围盒、体素区域分配、原始点分配、最终标签筛选 |
| `src/dynamic/ClusterGround.cpp` | 地面估计、地面点排除、原有平面拟合 |
| `src/dynamic/ClusterCompletion.cpp` | 邻域物体补全、保留最大连通分量 |
| `include/m-detector/DynObjCluster.h` | 参数、候选物体结构、接口与帧内工作区 |

## 调用顺序

`refineDynamicMask` → `clusterMotionSeeds` → `buildCandidates` → `assignCandidateRegions` → `assignScanPoints` → `refineCandidates`。

每个候选物体内部执行：地面估计 → 有地面时补全并排除地面 → 保留最大体素连通分量 → 种子比例筛选 → 输出标签。

每个 `ClusterCandidate` 自己保存包围盒、物体点、原始点索引、地面样本和生长体素。删除了以 ROS 协方差数组存包围盒边界的做法，以及生产代码中未使用的 OOBB、DBSCAN 入口和发布器。三张稀疏体素表在每帧开始、结束和异常退出时清理。

输入种子与完整扫描都使用 LiDAR 坐标；姿态仅用于把世界竖直方向转换到 LiDAR 坐标。调用处原来误导性的 `raw_points_world` 已改为 `scan_lidar`。

## 刻意保留的算法行为

- 保留现有 ROS 参数键名、配置值、处理顺序及重叠区域的顺序归属规则。
- 地面距离阈值 0.10 m，法向与竖直方向夹角判定约 30°。
- 平面仍使用 `n·x+1=0`；四维拟合结果的末项是平均拟合误差，不是平面偏移量。此表示无法一般性表达穿过原点的平面，本次未更换拟合算法。
- 补全是按既有体素顺序进行一次六邻域扫描，不是递归生长；局部法向与地面法向点积绝对值小于 0.8 才补全。
- 最大连通分量按占据体素数量选择，不按点数选择。
- 种子比例仍是原始种子数/最终候选点数，并非概率，也未重新统计存活种子，可能超过 1。
- 时间日志保留四列：种子聚类耗时、地面估计耗时、补全耗时、总耗时减补全耗时；计时改用 WallTime，避免仿真时钟影响性能测量。

增加了未初始化调用、标签长度不匹配和非法参数检查；空候选不再执行除零运算。

## 验证边界

新增 `test/cluster_pipeline_tests.cpp`，对空帧、越界点、带地面物体、不同姿态、相邻候选、比例筛选和连续帧进行新旧实现标签对照，另检查长度不匹配异常。`test/reference` 是本次重构前融合库代码的测试快照，仅改类名、包含路径和行续接格式；不是又安装一个库，也不是未经修改的上游 M-detector。

已检查源文件引用、接口声明/定义、配置 XML 和压缩包完整性。当前 Windows 环境没有 ROS/PCL 编译环境，因此没有运行 C++ 编译、gtest 或 rosbag 验证，不能据此断言运行结果已经完全等价。

在目标 ROS 工作空间运行：

```bash
catkin_make -DCATKIN_ENABLE_TESTING=ON
catkin_make run_tests_cc_mls_slam
catkin_test_results
```

类名已统一为 `MovingObjectCompletion`；源文件路径保留。完整命名对应见 [论文术语与代码命名](论文术语与代码命名.md)。
