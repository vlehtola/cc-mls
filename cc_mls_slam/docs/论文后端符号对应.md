# 论文后端符号与代码对应

按论文第3.5节、式(13)–(16)统一后端命名；本次不改变候选筛选、配准或优化规则。

| 论文术语/符号 | 代码 | 含义 |
|---|---|---|
| T_k | Keyframe::T_k | LIO估计的世界坐标系关键帧位姿 |
| 静态子集 | Keyframe::static_scan | LiDAR坐标系静态关键帧点云 |
| E_rev | E_rev | 已接受回访约束的关键帧对 |
| E_covis | E_covis | 已接受额外共视约束的关键帧对，不含单独记录的连续里程计边 |
| T_ij | T_ij | 共视相对位姿 T_i^{-1}T_j，由LIO计算 |
| z_ij | z_ij | 共视测量的无噪声值，协方差由因子噪声模型表达 |
| (p,q)、T_pq | p、q、T_pq | 历史/当前回访帧及GICP相对位姿 |
| z_pq | z_pq | GICP得到的回访测量 |
| Cauchy鲁棒核 | revisit_cauchy_noise_model | 回访因子的鲁棒噪声模型 |
| 优化变量 {T_k} | optimized_keyframe_poses | iSAM2优化后的位姿集合 |

GTSAM BetweenFactor(p,q) 使用 T_p^{-1}T_q；PCL 将当前q点云配准到历史p坐标系，所得矩阵正好用于这个测量。没有为了匹配符号而交换变换方向。实现没有随机采样论文的 n_ij/n_pq，测量不确定性通过噪声模型表达；当前对角噪声仍为工程近似，不宣称严格实现论文的信息矩阵Ω。

ROS参数名保留兼容：covisibility_overlap、covisibility_count、covisibility_enabled、revisit_overlap、gicp_max_fitness、overlap_distance、sc_distance_threshold。代码变量已改为完整术语；三个launch中的既有参数仍有效。上游 Scan Context 公共接口 detectLoopClosureID 保持不变。
